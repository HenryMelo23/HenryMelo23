### 🚀 About Me / Sobre Mim

Welcome to my GitHub profile! I am a passionate developer focused on **Game Development**, **Mobile Applications**, and **Artificial Intelligence**.

- 🎮 **Game Developer**: Building immersive 2D/3D games in **Godot Engine**, specializing in custom gameplay mechanics, time manipulation systems, and multiplayer state synchronization.
- 📱 **Mobile & Web Apps**: Creating cross-platform interactive applications like **Notas no Bolso** for musical note training.
- 🧠 **AI & Machine Learning**: Experimenting with **Deep Q-Learning (DQN)** and PyTorch for adaptive game AI behaviors.
- ⚡ **Always Learning**: Exploring network stabilization, rendering optimization, and modern software architecture.
